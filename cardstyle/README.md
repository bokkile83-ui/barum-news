# BARUM NEWS 카드 정본 — 유튜브 색감 (2026.11.14 지점장 확정)

매일 아침 예약 작업(뉴스 · 안부 · 블로그 · 공부/유튜브)이 만드는 카드뉴스는 전부 이 방식으로 만든다.
옛 방식(회색 바탕 + 흰 카드 + 파랑 제목)은 쓰지 않는다.

## 만드는 법
1. `cardstyle/template.html` 을 복사해 섹션 글만 바꾼다. CSS 는 고치지 않는다.
2. 그림은 `cardstyle/e3d/*.webp`(3D 이모지 256개, 목록 = `e3d/list.txt` 「코드 ⇥ 이모지」)에서 장마다 1개.
   복사한 html 위치에 맞게 경로를 고친다(예: news/cards/작업폴더 에서 `../../../cardstyle/e3d/1f4b8.webp`).
3. `node cardstyle/shot.js <html 경로> <저장 폴더>` → 01.png, 02.png … (섹션마다 1080×1080).
4. 다 찍은 뒤 전 장을 한 번 눈으로 본다. 글이 그림·흰 상자·아래 검은 띠와 겹치면 제목은 `.t.s`(96px), 숫자는 `font-size` 를 줄여 다시 찍는다.

## 규칙 (고정)
- 크기 1080×1080 정사각형. 카드 3~6장.
- 바탕색은 역할로 고정한다. 장마다 마음대로 바꾸지 않는다.
  - 1장 표지 = 초록 `cover`
  - 핵심·숫자 = 파랑 `key`
  - 바뀌는 점·주의·비교 = 주황 `warn`
  - 마지막 정리 = 남색 `end`
- 제목: 흰 글자 + 검은 테두리, 2줄 이내(한 줄 8글자 안팎), 꼭 짚을 말 하나만 노랑 `<span class="y">`.
- 큰 숫자(노랑 + 검은 테두리)는 장마다 하나만.
- ★숫자가 있는 장은 반드시 아래 `src` 줄에 조건과 출처를 쓴다: 「조건 · 매체 MM.DD」. 출처 없는 숫자는 넣지 않는다.
- 회사·상품마다 다른 것은 「상품별로 달라요」.
- 마지막 장: `end1` = 「같이 확인해 드릴게요.」 류의 행동 한 줄, `end2` = 「언제나, 늘 곁에」.
- 아래 검은 띠: 왼쪽 「BARUM 바름지점」, 오른쪽 「n / N」.
- 고객용 해요체. 보험금 지급 확정 · 가입 권유 · 가짜 마감 표현 금지.
- 개인 이름(지점장 이름 포함) · 고객 실명 · 전화번호 · 로고 · 「토스」 금지.
- 안부 카드는 계절·안부 그림(🍂 1f342, ☕ 2615, 🤝 1f91d 등)으로, 숫자가 없으면 큰 숫자 대신 흰 상자 한 줄.
