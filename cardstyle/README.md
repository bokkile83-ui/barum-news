# BARUM NEWS 카드 정본 — 「프리미엄 생활정보」 (2026.11.14 지점장 「하자 · 지금 이미지 너무 좋다」)

GPT(바름 프로젝트)가 그린 시안 4장을 HTML 로 옮긴 틀이다. 매일 아침 예약 작업(뉴스 · 안부 · 블로그 · 공부/유튜브)의 카드뉴스는 전부 이 틀로 만든다.
옛 방식(회색 바탕 + 흰 카드 + 파랑 제목)과 진한 원색 방식은 쓰지 않는다.

## 만드는 법
1. `cardstyle/template.html` 을 `<칸>/cards/YYYY-MM-DD-<짧은영문>/card.html` 로 복사한다. CSS 는 고치지 않는다.
2. 그림·글꼴 경로는 템플릿에 이미 `../../../cardstyle/art/`·`../../../cardstyle/fonts/` 로 맞춰져 있다(<칸>/cards/<폴더>/ 세 단계 아래 기준). ★경로 글자를 바꾸지 않는다(e3d 경로 바꾸기 지시가 있어도 템플릿엔 e3d 가 없다 — 보조 그림을 넣을 때만 `../../../cardstyle/e3d/파일` 로 적는다).
3. 섹션(장) 글과 그림만 바꾼다. 장 종류는 템플릿의 4가지를 골라 쓴다:
   - 표지(`.c`): 꼬리표 「오늘의 보험 뉴스」류 + 오른쪽 날짜 · 제목 2줄(핵심 말만 `<span class="b">` 파랑) · 큰 숫자 + 물결 · 요약 막대(`.bar`) · 조건·출처(`.src`) · 3D 그림 2~3개
   - 핵심 숫자(`.c.mint`): 제목 한 줄 · 큰 숫자 · 체크 줄(`.chk`) · 출처 · 3D 그림
   - 바뀌는 점·비교(`.c.peach`): 제목 2줄 · 흰 정보 상자(`.info` 의 `.r` 줄 2~3개 = 그림 + 이름 + 파랑 값 칩) · 출처
   - 정리(`.c` 마지막): 제목 2줄 · 설명(`.sub`) · 답 칩(`.ans` 「같이 확인해 드릴게요」류) · 하단 「언제나, 늘 곁에 · BARUM 바름지점」
   카드는 3~6장. 장이 늘면 핵심 숫자·바뀌는 점 장을 반복한다.
4. ★그림은 `cardstyle/art/*.webp`(GPT 가 그린 3D 일러스트, 배경 투명)를 쓴다. 장마다 2~3개를 겹쳐 오른쪽 아래에(주 그림 280~400px + 작은 것 170~230px), 글자·숫자를 가리지 않게. 지금 있는 것: shield_coin(방패+동전) · checklist · hospital · family(30~60대 3명) · calendar · hand_point(가리키는 손, 왼쪽을 가리키게 하려면 transform:scaleX(-1)) · medkit · doc_search(서류+돋보기) · coins · brain · heart · pills · stethoscope · car · piggybank · clock · house · megaphone. 주제에 맞는 그림이 없을 때만 `cardstyle/e3d/*.webp`(3D 이모지, 목록 e3d/list.txt)를 작게(150px 이하) 보조로 쓴다. 새 그림이 필요하면 GPT_PROMPTS.md 의 그림 프롬프트로 만들어 art/ 에 추가한다.
5. 찍기: `node barum-news/cardstyle/shot.js <card.html> <같은 폴더>` → 01.png, 02.png …  `[IMG_MISS]` 가 나오면 그림 경로를 고쳐 다시.
6. 다 찍고 전 장을 Read 로 눈으로 본다. 큰 숫자·제목이 그림과 겹치면 숫자 `font-size`(최소 150px)나 그림 크기·위치를 줄이고, 정보 상자 이름이 3줄로 꺾이면 값 글자를 줄여 다시 찍는다. 겹침 0 이 될 때까지.

## 규칙 (고정)
- 1080×1080 정사각형. 바탕 = 연한 하늘색 그라데이션 + 아래 곡선 레이어(템플릿 그대로). 글꼴 = Pretendard(cardstyle/fonts, OFL).
- 디자인 감각의 근거 = GPT_PROMPTS.md(GPT 카드 디자인 지시문). 장 종류별 기본 톤: 표지·정리 = 하늘, 핵심 숫자 = 민트, 바뀌는 점 = 피치.
- 제목 굵게, 검은 테두리 없음. 파랑은 핵심 말 하나와 큰 숫자에만.
- 큰 숫자는 장마다 하나.
- ★숫자가 있는 장은 반드시 `.src` 에 「조건 · 매체 MM.DD」. 출처 없는 숫자 금지. 일부 대상에만 해당하면 대상 조건을 꼭 쓴다(예: 「일부 초기 1·2세대 가입자 대상」).
- 회사·상품마다 다른 것은 「상품별로 달라요」.
- 하단 띠: 「BARUM 바름지점 | n/N」, 마지막 장은 「언제나, 늘 곁에 · BARUM 바름지점 | N/N」.
- 고객용 해요체. 보험금 지급 확정 · 가입 권유 · 가짜 마감 표현 금지.
- 개인 이름(지점장 이름 포함) · 고객 실명 · 전화번호 · 로고 · 보험사 이름(뉴스 출처 매체 제외) · 「토스」 금지.
- 안부 카드: 숫자가 없으면 큰 숫자 대신 `.sub` 설명 + `.ans` 칩, 그림은 계절·안부(🍂 1f342 · ☕ 2615 · 🤝 1f91d · 👋 1f44b).
