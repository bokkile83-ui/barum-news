# barum-news

바름 AI SYSTEM 앱 「📰 오늘의 보험 뉴스」 타일이 읽는 저장소. 예약 작업이 매일 아침 글을 덧붙인다(지우지 않고 쌓는다).

- `index.json` — 목록. `items` 한 줄 = `{"d":"YYYY-MM-DD","k":"news|anbu|blog","t":"제목","f":"news/YYYY-MM-DD.md"}`
- `news/` 매일 05:47 보험 뉴스 브리핑 · `anbu/` 월요일 06:17 고객 안부 초안 · `blog/` 평일 06:50 블로그·인스타 초안
- 고객 이름·전화번호는 넣지 않는다. 「토스」라는 단어는 쓰지 않는다.
